# Telegram заявки

`lead.php` принимает имя, телефон, согласие и выбранную услугу из формы в попапе на всех страницах. Он возвращает успех только после подтверждения Telegram. При ошибке введённые данные остаются в форме.

Токен хранится только на хостинге. Настройте переменные окружения PHP:

```
VERTO_TELEGRAM_BOT_TOKEN=<токен от BotFather>
VERTO_TELEGRAM_CHAT_ID=436390507
```

Или создайте `verto-private/telegram.php` **рядом с корневой папкой сайта, вне публичного доступа**. Например, при сайте `/home/account/public_html` конфигурация должна лежать в `/home/account/verto-private/telegram.php`:

```php
<?php
return [
    'token' => '<токен от BotFather>',
    'chat_id' => '436390507',
];
```

Для другого пути к приватному файлу задайте `VERTO_LEAD_CONFIG`. Не размещайте токен в HTML, JavaScript, GitHub, аргументах URL или публичной папке. Файл конфигурации должен читаться пользователем PHP; установите минимальные права, подходящие хостингу.

Получатель должен открыть бота в Telegram и нажать «Начать» перед первой заявкой. Нужны PHP 7.4+ и исходящий HTTPS к `api.telegram.org`, cURL или `allow_url_fopen`. Хранилище временных файлов PHP должно быть доступно для записи: там лежат только хеши IP и времена запросов для ограничения спама (5 запросов за 10 минут).

Без токена обработчик отвечает HTTP 503, а форма предлагает Telegram и телефон. Проверка после настройки: отправить явно обозначенную тестовую заявку, убедиться в её появлении в чате и в сообщении об успешной отправке в попапе.

Яндекс.Метрика `114134032` и Meta Pixel `1881270919425529` подключены на всех шести HTML-страницах. Скрипты запускаются на `verto.by` и `www.verto.by`; локальные предпросмотры не отправляют события. События `lead_form` (Метрика) и `Lead` (Meta) регистрируются после успешной доставки заявки.
